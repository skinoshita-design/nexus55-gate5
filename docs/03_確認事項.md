# 確認事項（実装前にリーダーへ確認したい点）

元仕様（Gate5 配布資料）に書かれておらず、`02_例外系仕様書.md` では下記のとおり**仮決め**した。違う場合は実装前に直す。

| # | 確認したいこと | 仮決め（02 の記載箇所） | 仮決めの根拠 |
|---|---|---|---|
| 1 | 1 人あたりの同時貸出台数 | 1 台（R-03） | 台帳では E-1042 が延滞中に 2 台目を借りている。これを防ぐ |
| 2 | 返却予定日の上限 | 14 日後（R-05） | 台帳の貸出期間は 7 日か 14 日。ひな形の 90 日は例のため採用しない |
| 3 | 休業日の定義 | 土日のみ。祝日は判定しない（R-05） | 祝日カレンダーが配布されていない |
| 4 | 延滞者への新規貸出 | 不可（R-04） | 台帳 L-021 → L-030 |
| 5 | 退職・休職者が既に持っている端末の回収 | 今回の範囲外。延滞表示（V-09）で気づけるようにするのみ | 台帳 L-024 は人事・総務の回収フローの問題 |
| 6 | employees の社員コード列 | `employee_code` を追加（3. データ定義） | 台帳が社員コード（E-1011）で出力されているが、元のテーブルに列がない |
| 7 | 管理者による代行返却 | なし。本人のみ（R-10） | 元仕様に管理者が出てこない |
| 8 | 既に存在する二重貸出データ（PC-0007 の L-022 / L-023、PC-0015 の L-025 / L-026）の是正 | 範囲外。事実を README に記載 | どちらが正しい借用者か台帳から判断できない |
| 9 | 認証方法 | `/login?user_id=○` で Cookie に保存する代用（Gate1 と同じ） | 元仕様に認証の記載がない |
| 10 | 技術構成 | Node.js + Express + SQLite + EJS（Gate1 と同じ） | 配布資料に指定がない |
| 11 | 貸出・返却以外の状態変更（修理・廃棄）の画面 | 今回の範囲外。遷移の可否判定のみ定義（4. 補足） | 元仕様に画面がない |
| 12 | 紛失・盗難の扱い | 扱わない（status は元仕様の 4 種のみ） | 元仕様にない |
