# Gate5 例外系洗い出し表（PC貸出処理）

- 対象：IT資産管理システム「PC貸出処理」（貸出申請 → 確認 → 完了 / 返却）
- 洗い出し項目数：**39 件**（8観点すべてに 3 件以上）
- 優先度の基準：**高** = データが壊れる／不整合が残る、**中** = 業務上おかしい、**低** = 見た目・使い勝手
- 「検知タイミング」= いつ・どこでチェックするか。「画面表示」= 何と出すか（文言ID は `02_例外系仕様書.md` の 9. を参照）
- 前提：台帳の日付は 2026 年、出力日は 2026/04/10（配布資料より）
